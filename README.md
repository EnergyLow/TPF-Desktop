# TPF Studio — Desktop App 🖥

Официальное десктопное приложение TPF Studio для Windows. Это нативный порт сайта, упакованный в быстрый и безопасный `.exe` файл на базе Electron.

Для установки вам не нужно ничего компилировать. Просто скачайте готовый установщик:

👉 **[Скачать TPF Studio для Windows (x64)](https://github.com/ВАШ_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ/releases/latest)** 👈

*(Ссылка ведет на страницу релизов. Скачайте файл `TPF Studio Setup x.x.x.exe` и запустите его).*

---

## ✨ Что внутри (Features)

- 🎵 **Музыкальный плеер** — кастомный плеер с синхронизацией текста песни по таймкоду.
- 🔒 **Безопасность** — `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`. Все внешние ссылки открываются в системном браузере.
- 🪟 **Нативный опыт** — поддержка горячей клавиши `F11` (полный экран), приложение запоминает размер и позицию окна.
- ⚙️ **Удобная установка** — инсталлятор NSIS с созданием ярлыков на рабочем столе и в меню «Пуск».
- 🌓 **Темы** — светлая и темная темы (сохраняются в памяти).
